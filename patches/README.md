# Modifications des dépôts externes

À réappliquer après un nouveau clonage (`git -C ~/workspace/sa2-nx apply <patch>`).

| Patch | Dépôt | Base | Objet |
|---|---|---|---|
| `sa2-nx-sdk.patch` | ~/workspace/sa2-nx (SDK : `sdk/`) | fdd6f14 | `WaitMissedCriticalSection` (rtl.h, xboxkrnl_rtl.cpp) : attente de la libération du verrou qu'un thread vient de rater avec `RtlTryEnterCriticalSection`, pour les `Sleep(0)` du moteur (src/od_sommeil.cpp). Générique, à proposer à sa2-nx. Et option du générateur `non_volatile_vectors_as_local` (config.h, config.cpp, builders/context.cpp ; vraie par défaut) : avec `non_volatile_as_local`, `false` laisse v14-v31 / v64-v127 dans le contexte et garde les appels réels à `__savevmx_N` / `__restvmx_N` (décodeur vidéo du jeu qui garde des constantes dans v64-v72 d'une fonction à l'autre). Reconstruire le générateur : `ninja -C ~/workspace/sa2-nx/sdk/out/host ~/workspace/sa2-nx/sdk/out/linux-amd64/rexglue` (chemin absolu). |
| `sa2-nx-sdk.patch` (suite) | idem | fdd6f14 | Option `REXGLUE_GLSLANG_HLSL` (sdk/thirdparty/CMakeLists.txt, désactivée par défaut ; bloc repris du SDK de nfsmw-nx) : glslang avec l'entrée HLSL et SPIRV-Tools (légalisation et optimisation du SPIR-V), pour la traduction des shaders en jeu (src/od_traducteur.cpp ; activée par notre CMakeLists.txt). |
| `glslang-verrou.patch` | ~/workspace/sa2-nx (`sdk/thirdparty/glslang`, non suivi par git : `git apply` depuis la racine de sa2-nx) | glslang du SDK | Verrou global de glslang initialisé une seule fois (repris de torchlight-nx) : `InitializeProcess()` le réinitialisait à chaque appel ; deux appelants pouvaient l'écraser pendant qu'un autre fil le tenait (blocage vu sur la Switch). |

Défaut d'origine de sa2-nx (limite de 50 ms entre deux énumérations), à lui signaler. |

| `sa2-nx-sdk.patch` (suite, 2026-11-05) | idem | fdd6f14 | Recherche de haut en bas de `BaseHeap::AllocRange` (system/xmemory.cpp, include/rex/system/xmemory.h), reprise de torchlight-nx 1.0.5 : compteur de pages prises par groupe de 64 (AllocFixed, AllocRange, Release, Restore, Reset), un groupe plein est sauté d'un coup, même résultat. `heap_recherche_rapide` (vrai), `heap_recherche_verif` (diagnostic : les deux recherches comparées).
